# Changes

## 0.1.0a1 — public technical preview

- Apache-2.0 licensing for the complete public core.
- Compact verified terminal triage and isolated-package CI checks.
- Original offline case store, bounded evidence acquisition, resumable parsing and byte-level record locators.
- OpenSSH/sudo, selected journal JSON and canonical event JSONL intake.
- Timestamp intervals with preserved source values, explicit corrections and unknown-time handling.
- Authentication/nearby-command correlation, conservative coverage reporting and analyst counterevidence.
- Verified reports, snapshots, replay, comparison and keyed share candidates.
- Keyboard-operated monochrome evidence browser, two synthetic investigations, reproducible benchmark and tests.

Known scope: POSIX; selected text/JSON artifacts; no disk, memory or raw EVTX support; local plaintext storage; bounded in-memory analysis; no commercial modules or licensing service.
