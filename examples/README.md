# Synthetic evidence only

`auth.log` contains eight failed SSH authentications and one public-key success. `activity.jsonl` contains one canonical process record. All names are fictional and `192.0.2.30` belongs to a documentation range. No command is executed by importing these files.

`testifex demo --directory demo-output` regenerates these exact input bytes and builds both complete cases, reports and a comparison. The second case declares a ±30-second error on the process source. Neither example proves that a process was linked to the SSH session or that activity was unauthorized.
